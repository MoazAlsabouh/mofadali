# نظام استخراج وتنقيح بيانات المفاضلات الجامعية السورية (2014 - 2026)
### Syrian University Admission Data Extraction & Interactive Curation Dashboard

مشروع متكامل لأتمتة استخراج بيانات المفاضلات السورية من ملفات الـ PDF (المفاضلة العامة والتعليم الموازي) للاختصاصات التقنية والبرمجية، وتخزينها في قاعدة بيانات SQLite محلية مع لوحة تحكم ويب تفاعلية للتنقيح اليدوي والتحليل.

---

## 🚀 المميزات الرئيسية

1. **محرك استخراج الجداول (`extract_to_sqlite.py`):**
   - استخراج الجداول بدقة باستخدام `pdfplumber`.
   - معالجة النصوص العربية وتصحيح الاتجاه المعكوس (RTL) والأخطاء الشائعة في تشفير الخطوط السورية القديمة عبر `python-bidi` و `arabic-reshaper`.
   - فلترة ذكية لاختصاصات (الهندسة المعلوماتية، هندسة الحواسيب والأتمتة، الاتصالات، الكليات التطبيقية، والمعاهد التقانية للحاسوب).
   - استخراج ديناميكي للسنة ونوع القبول (عام/موازي) وحالة الوثيقة (شروط تقدم مبدئية أم نتائج وحدود دنيا فعلية).
   - التزام صارم بفلترة "القبول لجميع المحافظات فقط" واستبعاد الكوتات الخاصة.

2. **لوحة تحكم الويب والتنقيح اليدوي (`web_app.py`):**
   - **تنقيح وتعديل مباشر (Full CRUD):** إمكانية تعديل درجات وتفاصيل أي سطر أو حذفه مع الحفظ التلقائي في قاعدة البيانات.
   - **مساعد الملفات الممسوحة ضوئياً:** نافذة خاصة بالملفات الممسوحة كصور لتسهيل إدخال درجاتها يدوياً مع ملء الحقول تلقائياً.
   - **بحث وتصفية لحظية:** تصفية بحسب السنة، الجامعة، نوع القبول، والحالة.
   - **مخططات بيانية تفاعلية:** متابعة منحنى الحدود الدنيا الفعلية عبر السنوات باستخدام `Chart.js`.
   - **تصدير إكسل:** تصدير فوري للبيانات بترميز UTF-8-BOM المتوافق مع اللغة العربية في Microsoft Excel.

## 🛠️ التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل سكربت استخراج البيانات من الـ PDF:
```bash
python extract_to_sqlite.py
```

### 3. تشغيل لوحة التحكم الويب:
```bash
python web_app.py
```
ثم افتح الرابط في المتصفح: `http://localhost:5000`

---

## 🗄️ مخطط قاعدة البيانات (`mofadala.db`)

جدول `admission_data`:
* `id`: معرف فريد (INTEGER PRIMARY KEY)
* `year`: السنة الدراسية (INTEGER)
* `university`: اسم الجامعة أو المدينة (TEXT)
* `specialization`: الاختصاص أو الكلية (TEXT)
* `admission_type`: نوع القبول (عام أو موازي) (TEXT)
* `is_final_result`: هل هو نتيجة نهائية/حد أدنى فعلي (BOOLEAN)
* `score`: العلامة أو النسبة المئوية المطلوبة (REAL)
